# Flashcards do ciclo

Os flashcards ficam dentro de cada nota de tópico, na seção **Flashcards**, no formato `Pergunta::Resposta`.

## Como revisar
1. Instale o plugin comunitário **Spaced Repetition** (*Configurações → Plugins da comunidade → Procurar*).
2. Clique no ícone de cartas na barra lateral → escolha o baralho `flashcards/<matéria>`.
3. Responda *Difícil / Bom / Fácil*: o plugin agenda a próxima revisão sozinho.

Dica: faça 10–15 minutos de revisão por dia, antes do primeiro bloco.
