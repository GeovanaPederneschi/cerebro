# Cérebro

Cofre do Obsidian com o ciclo de estudos do [CicloAI](https://github.com/GeovanaPederneschi/ciclo-ai).

- `CicloAI/Ciclo de Estudos.md` — o ciclo (11 matérias, editável e sincronizado com o app)
- `CicloAI/Plano das 15 voltas.md` — tópico de cada matéria em cada volta
- `CicloAI/Matérias/` — uma nota por matéria, com roteiro em checklist
- `CicloAI/Tópicos/` — uma nota por tópico: resumo, conceitos, flashcards e conexões

## Como abrir
1. `git clone https://github.com/GeovanaPederneschi/cerebro.git`
2. Obsidian → *Open folder as vault* → escolha a pasta `cerebro`
3. Plugins da comunidade: **GitHub Sync** (remote: a URL deste repo), **Spaced Repetition** e **Dataview**
